# oxml-json 0.0.11

Release preparation dated 2026-10-17. This file does not announce a
publication or authorize a tag.

## Highlights ⭐️

* **Bounded JSON ingress**: Reject sources above 16 MiB and more than 256 nested containers before growing parser state further.
* **Strict lexical syntax**: Reject invalid number spellings, unknown escapes and raw control characters while preserving valid JSON round trips.
* **Family and packaging integration**: Set the package to 0.0.11, package declared benchmarks, and keep laptop release checks dry-run-only.

## Upgrade notes
